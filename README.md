# Aviation Analytics Dashboard

End-to-end SQL + Power BI analysis of 150,000 airline flight records.

## 🔗 View the Dashboard
📄 [PDF Version](https://drive.google.com/file/d/1gpkv3al-aOJMcwz5xlxQohLw8LCJh-Z6/view?usp=drive_link)

## 📊 Dashboard Pages
1. *Executive Overview* — Flight volumes, KPIs, top routes
2. *Delay Analysis* — Delay drivers, weather impact, airport performance
3. *Route & Profitability* — Profit margins, revenue vs cost
4. *Customer Satisfaction* — Delay impact on satisfaction

## 🔍 Key Insights
- Average departure delay: 119 minutes
- Only 6.6% of flights on-time (<15 min)
- Weather (storm, snow) drives the highest delays
- Delayed passengers report lower satisfaction

## 🛠️ Tech Stack
- *MySQL*: Data loading, view creation, 12+ analysis queries
- *Power BI*: DAX measures, interactive dashboards, slicers
